One QR code. One review per customer.

Put the code on the counter, the receipt or the table. Customers scan it, read your latest reviews, and leave one of their own - helped by drafts written from exactly what they told you, and nothing else.

A code per venue

Every business gets its own page and its own QR code, as PNG or print-ready SVG. The address never changes when you edit the business, so a printed code keeps working.

One review per person

Verify by email or Google sign-in, both optional per business. Either way a customer leaves one review, and the same person cannot review twice from a second phone.

Drafts, not inventions

The customer picks a rating and taps a few topics. Drafts are built from those details only - no invented prices, places or dates - and every one is editable before posting.

How it works

  1. A customer scans your code and lands on your profile.
  2. They verify once, if you have asked for it. Returning customers skip this.
  3. They pick a star rating, tap a few topics and add an optional note.
  4. They choose one of the suggested drafts, edit it, and post it.
  5. You answer it from the admin console, and the answer shows under the review.

Run a business?

Create it in the admin console, print its code, and start collecting. You will need the admin password from the server's environment.
